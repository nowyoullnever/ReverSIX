# Third-party notices

## HARD model

`public/model/hard/` contains the r4 iteration 54 AZ-32 model published by
[donghoon0709/reversix](https://github.com/donghoon0709/reversix), retrieved from
its `public/model/latest.*` assets.

## EASY strategy reference

The EASY evaluator is an original, small 10 by 10 implementation based on common
Othello positional ideas, with the corner, X-square, C-square, edge, and flip-count
priorities informed by [boisedude/othello-game](https://github.com/boisedude/othello-game).
No source code from that project is included.
